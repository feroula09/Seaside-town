# Seaside Town — 產品需求文件（PRD）

> 版本：v0.1（草稿）　|　日期：2026-10-13　|　狀態：待評審
> 參考對象：「Harbor Jelly」（Material Studies）網頁互動作品截圖兩張（Cosmos、Sunset 氛圍）

---

## 1. 概述

### 1.1 一句話描述
一個在瀏覽器中執行的 **3D 微縮港口模型（Diorama）互動玩具**：整片海水是一塊可以戳、可以搖、會晃動的「果凍」，玩家在漂浮於天空／宇宙中的港口方塊上觀察貨輪卸貨、出港、餵魚，並自由切換鏡頭、天氣氛圍與果凍口味。

### 1.2 產品定位
- **類型**：療癒系沙盒玩具（Toy / Sandbox），輕度目標驅動（卸貨、出航、餵魚計數）。
- **平台**：桌面瀏覽器優先（Chrome / Edge 113+，WebGPU），WebGL2 作為後備；行動裝置為 P2。
- **核心賣點**：
  1. 「果凍海」材質：半透明、可看見海底的剖面方塊，具有彈性的物理反饋。
  2. 精緻低多邊形（low-poly）港口小鎮，充滿可看的小細節與動態。
  3. 一鍵切換的四種氛圍（白天／夕陽／夜晚／宇宙）與三種果凍口味。

### 1.3 命名說明
本專案代號 **Seaside Town**。介面與美術將以參考作品為「風格與玩法」藍本自行製作，**不直接使用原作名稱、Logo 或資產**，避免著作權與商標問題（見 §14 風險）。下文提到的 UI 字串為功能描述，正式文案可另行決定。

## 2. 目標與非目標

### 2.1 目標
| # | 目標 | 衡量方式 |
|---|------|----------|
| G1 | 視覺上達到參考截圖的品質與氛圍 | 與參考圖並排比對，主要元素（§5）全部到位 |
| G2 | 「果凍海」手感好玩、反應即時 | 拖曳水面到看見波紋延遲 < 1 幀；60 FPS |
| G3 | 有輕量的遊戲循環讓人想停留 | 卸貨 → 出航 → 回港 循環可無限進行，計數器正確 |
| G4 | 開箱即玩，無需教學 | 底部一行操作提示即足以理解全部操作 |

### 2.2 非目標（v1 不做）
- 多人連線、帳號系統、雲端存檔。
- 經濟系統、升級、商店等深度經營玩法。
- 真實流體模擬（SPH/FLIP）；以高度場波動 + 整體彈性近似即可。
- 原生 App 打包。

### 4.2 觀察到的元素清單
- **方塊（Diorama Block）**：正方形底座，側面為帶波浪狀地層紋理的剖面；海水區域佔約 2/3，陸地（山坡＋碼頭）佔後側與右側。
- **果凍海**：半透明、邊緣有菲涅耳亮邊與柔和的次表面散射感；可看到海床上的岩石、海草、沉船殘骸／管線、小魚。水面有細碎波紋與焦散（caustics）光斑。
- **山坡小鎮**：約 60–80 棟彩色斜屋頂房屋，分層錯落，含一座帶尖塔的教堂、樹木、路燈；夜間／宇宙模式窗戶發光。
- **貨櫃碼頭**：2 座大型門式起重機（紅、藍）、成堆彩色貨櫃、倉庫、拱形岸壁、靠港的貨櫃船（甲板上載滿貨櫃）。
- **木棧碼頭（Pier）**：木製棧橋、繫泊的小漁船與帆船、梯子、繫纜樁。
- **防波堤與燈塔**：紅白條紋燈塔、混凝土防波堤、消波塊／亂石堆。
- **水上物件**：綠色浮標、橘色救生圈（可丟擲）、會移動並拖出白色尾跡的小艇。
- **背景**：
  - Sunset：粉紫→米黃漸層天空、柔光太陽圓盤、暖色光照。
  - Cosmos：像素風星系、星雲、帶環行星、像素月球、閃爍星星；冷色調光照，窗戶發光。

## 5. 核心體驗與遊戲循環

### 5.1 體驗支柱
1. **觸感（Tactile）**：每一次點擊、拖曳都有柔軟、彈性、Q 彈的視覺與聲音回饋。
2. **觀賞（Ambient）**：不操作時，港口也在自己運作——起重機卸貨、小艇巡航、燈塔旋轉、海鷗飛過。
3. **小目標（Light goals）**：右上面板的計數器提供輕量成就感。

### 5.2 主循環（狀態機）
```
          ┌──────────────┐  每卸下 1 箱  ┌──────────────┐
  開始 ──▶│ Unloading n/8 │─────────────▶│  Boxes +1    │
          └──────┬───────┘               └──────────────┘
                 │ 8/8 完成 或 玩家按「Cast off」
                 ▼
          ┌──────────────┐  駛離畫面外   ┌──────────────┐
          │  Departing   │─────────────▶│  At Sea（隱藏）│
          └──────────────┘               └──────┬───────┘
                                                │ 計時 15–25s
          ┌──────────────┐◀──────────────────────┘
          │  Arriving    │ 新船（新貨櫃配色）入港
          └──────┬───────┘  Voyages +1（返港時結算）
                 ▼
          回到 Unloading 1/8
```
- **Unloading n/8**：起重機自動將船上貨櫃逐一吊到岸上堆場，每箱約 3–5 秒；面板標題顯示 `Unloading n / 8`，下方有進度條。
- **Cast off**：任何時刻可按下，船鳴笛、解纜、沿航道駛出方塊邊緣（淡出），未卸完的箱子不計入。
- **Voyages**：每完成一次「出港→返港」+1。
- **Feed the fish**：在水面隨機位置灑飼料粒子，魚群聚集啄食，`Fed +1`；冷卻 2 秒。
- **Horn**：播放船笛音效，附近海鷗受驚飛起、水面產生一圈低頻漣漪。

### 5.3 自由互動
| 操作 | 行為 | 優先級 |
|------|------|--------|
| 左鍵拖曳水面 | 在游標處對高度場施加衝量，產生波浪並推動漂浮物 | P0 |
| 拖曳方塊側面 | 「推倒」整塊方塊：方塊以底邊為軸傾斜，放開後彈回；海水像果凍般晃動、晃出慢動作的浪 | P0 |
| 點擊／甩出救生圈 | 從游標位置拋出救生圈，落水濺起水花並隨波漂浮；上限 12 個，超出時最舊的淡出 | P0 |
| 右鍵拖曳 | 環繞（Orbit）鏡頭 | P0 |
| 滾輪 | 縮放（有上下限） | P0 |
| 按 `V` | 切換為第一人稱步行（WASD + 滑鼠視角，限於陸地與碼頭範圍） | P1 |
| 點擊船／起重機／燈塔 | 小動畫彩蛋（燈塔閃光、起重機鳴響、船晃動） | P2 |

## 7. UI 規格

### 7.1 版面
- **左上**：小標（全大寫、字距寬、低對比）＋ 大標題（襯線斜體，約 40px）。
- **右上**：渲染狀態膠囊 `● WebGPU · {Atmosphere}`；綠點表示 WebGPU 正常，黃點表示 WebGL2 後備。

## 8. 氛圍（Atmosphere）與口味（Flavour）規格

### 8.1 氛圍預設
| 參數 | Day | Sunset | Night | Cosmos |
|------|-----|--------|-------|--------|
| 背景 | 淡藍→白漸層、少量雲 | 粉紫→米黃漸層、太陽圓盤 | 深藍漸層、星點、月亮 | 像素風星系、星雲、帶環行星、像素月球 |
| 主光方向／色溫 | 高角度、白偏暖 | 低角度、橘粉 | 月光、冷藍、低強度 | 冷紫藍、中強度 |
| 環境光 | 亮、偏藍 | 暖粉 | 暗藍 | 紫藍 |
| 窗戶／路燈 | 關 | 少數亮 | 全亮 + Bloom | 全亮 + Bloom |
| 燈塔光束 | 關 | 關 | 開 | 開 |
| 面板主題 | 淺色 | 暖棕玻璃 | 深藍玻璃 | 深靛玻璃 |
| 霧 | 淡 | 暖色霧 | 深色霧 | 無霧（星空清晰） |

切換時所有參數以 1.5 秒插值過渡，背景交叉淡化。

### 8.2 果凍口味
| 口味 | 淺水色 | 深水色 | 感覺 |
|------|--------|--------|------|
| Sea glass | #BFEDE6 | #3FA9B5 | 預設，海玻璃青綠 |
| Blueberry | #B9C8FF | #3B4FC4 | 藍莓紫藍 |
| Lime | #DDF5B0 | #6FB43F | 萊姆黃綠 |

口味只影響果凍海的吸收色、散射色與邊光色，不影響其他場景。

### 8.3 物理參數對應
| 滑桿 | 影響 |
|------|------|
| Firmness | 波速 c、方塊彈簧剛度 k；越高越「硬」，晃動頻率越高、幅度越小 |
| Wave damping | 高度場每幀衰減係數、方塊彈簧阻尼；0 = 幾乎不停，1 = 快速平息 |
| Tide | 水面基準高度；漂浮物、船隻、碼頭繫纜同步調整；漲潮時淹沒最低一階台階 |

## 9. 美術規格

- **風格**：低多邊形、平滑著色、柔和粉彩色系，帶微縮模型（tilt-shift）質感。
- **建模方式**：建議以程式化生成（procedural）為主：房屋、貨櫃、樹木、路燈由少量參數化模組組合，使用 **Instancing** 繪製。必要的特殊物件（燈塔、起重機、貨輪、教堂）以 Blender 製作 glTF（Draco/Meshopt 壓縮）。
- **房屋**：牆面 6–8 種粉彩色、屋頂 4–6 種（紅、橘、藍灰、深灰），窗戶以貼圖或 emissive mask 實作夜間發光。
- **方塊剖面**：以 shader 生成多層 noise 波浪地層（3–5 層色帶），配色隨氛圍輕微調整。
- **背景（Cosmos）**：像素風 2D 圖層（星系、行星、月球、閃爍星星），可用離線製作的 PNG + shader 閃爍，或完全程式化生成。
- **資源預算**：總下載 < 8 MB（壓縮後），首屏可互動時間 < 3 秒（寬頻）。

## 10. 技術方案

### 10.1 技術選型
| 項目 | 選擇 | 理由 |
|------|------|------|
| 語言／建置 | TypeScript + Vite | 快速開發與 HMR |
| 渲染 | **Three.js `WebGPURenderer` + TSL**（自動回退 WebGL2） | 一套著色器同時支援 WebGPU / WebGL2；生態成熟 |
| UI | 原生 DOM + CSS（或輕量 Preact / Svelte） | 面板簡單，不需重框架 |
| 狀態 | 小型 store（如 zustand vanilla 或自寫 event emitter） | UI ↔ 模擬解耦 |
| 音效 | Web Audio API（必要時 Howler.js） | 低延遲、可程式化合成船笛與彈性音 |

### 10.3 關鍵演算法
- **高度場**：`h_next = (2h - h_prev + c²Δt²∇²h) * (1 - damping)`，以 compute shader 執行於兩張 R32F 貼圖 ping-pong；邊界為反射邊界，陸地區域以 mask 固定為 0。滑鼠拖曳沿路徑注入高斯擾動。
- **果凍方塊**：方塊狀態為二維傾角 θ 與剪切位移 s，各自為 `θ'' = -kθ - cθ' + τ_user`；頂點 shader 依高度做剪切變形（頂部位移大、底部固定）呈現 Q 彈感。傾角同時以 `∂h/∂x ∝ θ` 的形式回饋給高度場，產生晃動。
- **浮力**：每幀將高度場降採樣（64×64）讀回 CPU（WebGPU `mapAsync`，延遲一幀可接受），漂浮物取樣 4 點求高度與傾角，以彈簧追隨。
- **果凍海著色**：Beer–Lambert 深度吸收 + 菲涅耳 + 螢幕空間折射（取場景深度與顏色緩衝）+ 簡化次表面（以 view·light 背光項近似）；剖面側面使用同一材質並加厚度漸層。
- **焦散**：以 2–3 層滾動 Voronoi／預烘焙焦散貼圖投影到海床，強度與水深成反比。

## 13. 驗收標準（P0）
1. 打開頁面 3 秒內可見完整港口方塊，並顯示 `● WebGPU · Sunset`（或 WebGL2）。
2. 在水面拖曳時，游標處即時產生向外擴散的波紋，救生圈與浮標隨之起伏。

7. 六個視角按鈕皆能平滑切換；Reset view 回到預設視角；右鍵拖曳可環繞。

9. Tide 滑桿使水位升降並顯示 cm 數值。
10. Pause 凍結模擬；Reset 重置所有計數與物件；Sound 切換有效。

## 14. 風險與對策
| 風險 | 影響 | 對策 |
|------|------|------|
| 著作權／商標：直接複製原作名稱、UI 文字、美術 | 法律風險 | 使用自有名稱與自製資產；玩法與風格參考屬一般靈感範疇；上線前檢查 |

| GPU→CPU 讀回造成卡頓 | 效能 | 低解析度、非同步、延遲一幀；或在 GPU 端計算漂浮物 |
